# Credits: OpenRISC 1000 module

This module is a community SLEIGH module that Ghidra-Rare imported, tested and fixed. The
processor specification was written by its original authors; Ghidra-Rare added the changes
listed below.

## Ghidra-Rare changes

Each item names the problem and how it was found.

1. **Delay slots restored on big endian.** The LE hack commented `delayslot(1)` out of the
   shared include, which removed delay slots from the big-endian language as well. The
   no-delay behaviour is now a `NO_DELAY_SLOT` preprocessor variant used only by the LE
   language, and the two `.slaspec` files share one specification. Found by code review.
2. **Link address of `l.jal`/`l.jalr`.** `r9 = inst_next + 4` gave jump + 12 with a delay slot
   (SLEIGH's `inst_next` already skips the slot) and jump + 8 without one. Both are now
   `inst_next` (jump + 8 / jump + 4, arch manual 1.4). Found by emulator tests, and by a
   misread jump table in glibc, because PIC code adds r9 to the GOT offset.
3. **"`l.jal 8`" reads the PC; it is not a call.** PIC code reads the PC this way. Modelled
   as a call, it split every glibc function in two: ldconfig had 2,314 functions and 34 KB of
   undisassembled `.text`, and now has 1,342 functions and 16 bytes. Found by real binaries.
4. **Reserved bits.** Decoding now uses the binutils 2.45 opcode masks. Before, about 12,000
   of 50,000 random words decoded where objdump rejects them. Found by differential fuzzing.
5. **Operands.** `l.slli`/`l.srli`/`l.srai`/`l.rori` have a 6-bit shift field. `l.adrp`
   showed its page without the instruction's own page. Found by differential fuzzing.
6. **Missing instructions.** All of ORFPX32 and ORFPX64A32 were missing: single-precision
   float, double precision on register pairs, `lf.stod.d`/`lf.dtos.d`, and `lf.rem`,
   `lf.madd` and `lf.cust1`. They are generated by `gen_orfpx.py`. Found by differential
   testing.
7. **Semantics.**
   - `l.sys` was a goto to the 0xc00 vector, so every function ended at its first system
     call. It now falls through as `r11 = syscall(K, r11, r3..r8)`.
   - `l.trap` falls through, and `l.rfe` is a return.
   - Register shift amounts are taken mod 32.
   - `l.mul`/`l.muli` set OV on signed 32-bit overflow.
   - `l.ff1`/`l.fl1` use popcount/lzcount instead of loops.
   - `l.cmov` is branch-free. Its internal `goto inst_next` skipped the enclosing jump when
     gcc put it in a delay slot (found in a gcc `-mcmov` build).
   - `l.macrc` no longer calls a pcodeop that stopped the emulator.
8. **Spec files.**
   - ELF opinion: EM_OPENRISC 92, and the old 0x8472.
   - DWARF register map.
   - `pc` register in the pspec.
   - cspec: 64-bit arguments in register pairs (join rule); r9 killed by calls; prototype
     named `__stdcall`, without which every DWARF-typed function decompiled with "Unknown
     calling convention".
   - gnu external names in the ldefs.
9. **ELF relocation handler** (`R_OR1K_*`). Before it, glibc's 1,063 dynamic relocations
   were not applied.
10. **ELF extension.** It sets r16 = GOT over `.plt` and names PLT entries after their
    `JMP_SLOT` symbols, so PIC PLT stubs become thunks.
11. Compiled `.sla` files are no longer tracked.

`l.muldu` keeps the architecture manual's encoding (secondary opcode 0xc, also used by QEMU);
binutils uses 0xd. See README.
